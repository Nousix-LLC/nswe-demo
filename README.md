# nswe-demo

A live demonstration of **NSWE** — the Nousix software-engineering application — building and operating a real
software project autonomously.

Everything in this repository after this README is authored by NSWE: the project plan on the **Projects** tab, the
issues, the pull requests and their reviews, the CI/CD in GitHub Actions, the ArgoCD deployment to a k3s cluster, and the
bug reports and fixes that follow. The goal it was given: a small web-application framework and a Twitter-style clone
built on it, production quality, in Rust/WebAssembly.

The repository's history — tickets, PRs, reviews, deploys — is the record of how the work was planned and done.

## Contributions

This is a closed demonstration, not a community project. It does not accept contributions: issues, pull requests and
comments are limited to the repository's collaborators.
